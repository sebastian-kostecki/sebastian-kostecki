### How I work with AI

Specs, a domain glossary and ADRs come first. Agents (Claude Code, Cursor) write much of the code; tests, static analysis and review decide what ships. Every change leaves a documentation folder in the repository — see the `context/` folders of the projects above. I am refining this workflow in the 10xDevs course.
